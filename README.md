# BANK-CUSTOMER-DASHBOARD
This Power BI Bank Customer Analytics Dashboard shows customer details, account information, balances, credit scores, and customer activity. It helps users easily understand customer data, compare account details, find useful patterns, and analyze bank performance using simple charts, KPI cards, filters, and visualizations.
# 🏦 Bank Customer Analytics Dashboard

## 📊 Project Overview

This project is a **Bank Customer Analytics Dashboard created using Power BI**.  
The dashboard helps to understand customer information, account details, balances, credit scores, and customer activity.

## 🎯 Key Features

- Total Customers
- Customer Details
- Account Information
- Account Balance
- Credit Score
- Customer Activity
- Customer-wise Analysis
- Financial Data Analysis
- Customer Performance

## 🛠️ Tools Used

- Power BI
- Data Visualization
- Data Analysis
- Power Query
- DAX

## 📈 Dashboard

The dashboard provides a simple view of bank customer data and helps identify important patterns in customer accounts, balances, credit scores, and customer activity.

This project helped me improve my skills in **Power BI, data visualization, data analysis, and bank customer data analysis**.
